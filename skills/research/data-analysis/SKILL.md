# 数据清洗与统计

## 任务边界
本 Skill 是教学集成定义，模型输出不能代替原始证据、实验测量、审稿判断或专利代理专业意见。第三方项目仅列为参考来源，当前没有宣称外部脚本已运行。

## 输入
脱敏数据、字段说明、目标

## 输出
代码、质控表、结果

## 阶段执行
1. 保留原始数据。
2. 数据画像。
3. 检查方法假设。
4. 隔离执行。
5. 复核统计解释。

## 强制质量门
- 标记信息状态：VERIFIED / PENDING / UNSUPPORTED，禁止把未经核验内容带入正式稿。
- 把关键数字、引文及研究事实与原始资料位置对应；不编造实验结果、DOI、前期成果或可专利性结论。
- 对外提交、上传、覆盖、删除及无法回滚的动作必须人工批准。
- 保存阶段输入、输出、来源和问题清单，失败时停止或回退，不得伪报成功。
