# 模板原件与使用范围

文件是从公开下载页取得的原件，下载记录及 SHA256 在 acquisition.json。原件不覆盖；填写时复制到案例工作目录。模板解析文字用于定位，不能替代原版式检查。

| 任务 | 原件 | 发布与适用范围 |
| --- | --- | --- |
| Grant | originals/grant-0.rar，解包后包含四份 DOC | 陕西农林职业技术大学科研处 2026 年 1 月 8 日转载发布的面上、青年 C 申请书正文及填写说明。正式申请以国自然系统当年度文件为准；不能推广至全部基金类别。 |
| Patent 通用 | originals/patent-1.doc | 中国科学技术大学先进技术研究院公开提供的发明或实用新型技术交底书通用模板。用于内部技术交底，不能当作法定申请文件。 |
| Patent 生化 | originals/patent-0.docx | 同一公开页面提供的生化领域材料，内部包含硼硅玻璃配方的具体示例；属于已有示例，不能冒认成课程学员的发明或实测结果。 |
| Paper | originals/paper-0.zip | PLOS 官方 LaTeX 模板，含 TEX、BST、BIB 和参考 PDF。模板内部示例文献和结果均不能直接带入新稿件。 |
| Figure | examples/figure/*/input/material.json | 课程自制绘图任务说明，分别演示公开数据图、假说框架和缺少误差信息的情况。没有统一官方科研图模板；投稿时另核对目标期刊图件要求。 |

公开来源：

- 基金转载页：https://kyc.ylvtc.cn/info/1009/2729.htm
- 国自然填报系统：https://grants.nsfc.gov.cn/pmpweb/psn-index
- 高校交底模板页：https://iat.ustc.edu.cn/iat/wdxz/20220329/5625.html
- PLOS 模板页：https://journals.plos.org/plosone/s/latex
- PLOS 稿件要求：https://journals.plos.org/plosone/s/submission-guidelines

下载过程中燕山大学附件入口要求验证码，没有绕过。采用上述公开可取的高校原件。下载页缓存保留在 originals/；HTML 缓存不是模板文件。
