# 四类科研任务示例提示词

每组对应examples中的实际目录。第一组用于教学草稿，其他组用于材料缺失、无依据主张或假说处理。预期行为是验收要求，不是模型已运行的记录。

使用前先确认当前Runner可以读取本地文件、运行所需工具并保存结果。仅能聊天的模型需要操作者上传明确授权的材料，不能把建议步骤称为已执行。

在桌面Codex中独立运行时，建立新的运行目录，保留原件，保存输入定位、工具日志、文件与问题。导出后重新打开；有渲染工具时逐页检查，缺工具则明确待审查。
