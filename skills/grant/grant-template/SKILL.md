# 申报指南解析

## 任务边界
本 Skill 是教学集成定义，模型输出不能代替原始证据、实验测量、审稿判断或专利代理专业意见。第三方项目仅列为参考来源，当前没有宣称外部脚本已运行。

## 输入
资助指南、官方Word模板

## 输出
章节要求映射、缺口清单

## 阶段执行
先读 [本地科研工作流操作规程](references/local-research-sop.md) 中的共同约定与 Grant 部分，按 G1–G6 执行；本 Skill 负责 G2。将原始标题、填写说明、字数限制、材料落点和缺口逐项写入 template-map.json。不存在官方模板时进入 NEEDS_INPUT，不自行把课程结构稿标成官方模板。原件只读，导出填充副本。

1. 提取资助边界。
2. 章节/字数。
3. 指标。
4. 资料映射。
5. 保留原始模板。

## 强制质量门
- 标记信息状态：VERIFIED / PENDING / UNSUPPORTED，禁止把未经核验内容带入正式稿。
- 把关键数字、引文及研究事实与原始资料位置对应；不编造实验结果、DOI、前期成果或可专利性结论。
- 对外提交、上传、覆盖、删除及无法回滚的动作必须人工批准。
- 保存阶段输入、输出、来源和问题清单，失败时停止或回退，不得伪报成功。
