# 科研数据图

## 任务边界
本 Skill 是教学集成定义，模型输出不能代替原始证据、实验测量、审稿判断或专利代理专业意见。第三方项目仅列为参考来源，当前没有宣称外部脚本已运行。

## 输入
真实数据副本、图表目的

## 输出
脚本、SVG/PNG图与图注

## 阶段执行
先读 [本地科研工作流操作规程](references/local-research-sop.md) 中的共同约定与 Figure 部分，按 F1–F5 执行。必须从实际数据复算并保留源行号。只有均值而没有样本量与变异信息时，不能生成置信区间。数据图保存脚本、SVG、PNG、统计量和来源图注；生成机制图与数据图分别标注。

1. 数据画像。
2. 图型选择。
3. 脚本绘制。
4. 数值与误差核验。
5. 保存绘图环境。

## 强制质量门
- 标记信息状态：VERIFIED / PENDING / UNSUPPORTED，禁止把未经核验内容带入正式稿。
- 把关键数字、引文及研究事实与原始资料位置对应；不编造实验结果、DOI、前期成果或可专利性结论。
- 对外提交、上传、覆盖、删除及无法回滚的动作必须人工批准。
- 保存阶段输入、输出、来源和问题清单，失败时停止或回退，不得伪报成功。
