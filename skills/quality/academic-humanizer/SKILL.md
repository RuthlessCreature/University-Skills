# 专业学术表达修订

## 任务边界
本 Skill 是教学集成定义，模型输出不能代替原始证据、实验测量、审稿判断或专利代理专业意见。第三方项目仅列为参考来源，当前没有宣称外部脚本已运行。

## 输入
作者草稿、需要保留的术语数字

## 输出
语言修改稿及差异清单

## 阶段执行
1. 标记不可修改字段。
2. 去空话。
3. 术语与逻辑修订。
4. 事实与引用不变。
5. 复查披露政策。

## 课堂语言审阅
- 逐句读出，改掉拗口的名词堆叠、口号、重复的总结句和无依据的程度副词。
- 用具体任务、材料和判断写作。讲师备注说明怎么解释案例，不重复“本页很重要”“先看证据再看结论”等制作套话。
- 不把每个问题硬拆成三点，不为版式补齐对称句。段落、对照、表格按内容选用。
- 改写前锁定数字、术语、引用、条件和否定词。改写后逐项比对，不能把关联改成因果、计划改成成果。
- 真实材料、教学模拟和生成内容的标识必须保留。自然表达不等于掩盖材料属性。

## 强制质量门
- 标记信息状态：VERIFIED / PENDING / UNSUPPORTED，禁止把未经核验内容带入正式稿。
- 把关键数字、引文及研究事实与原始资料位置对应；不编造实验结果、DOI、前期成果或可专利性结论。
- 对外提交、上传、覆盖、删除及无法回滚的动作必须人工批准。
- 保存阶段输入、输出、来源和问题清单，失败时停止或回退，不得伪报成功。
