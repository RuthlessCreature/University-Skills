# 科研工作流与 Skill 对照

## topic-review

`research-intake` → `literature-discovery` → `literature-synthesis` → `citation-verification` → `topic-evaluation` → `claim-audit`

## literature-review

`research-intake` → `document-parsing` → `literature-discovery` → `literature-synthesis` → `citation-verification` → `claim-audit`

## experiment-design

`research-intake` → `literature-synthesis` → `experiment-design` → `diagram` → `claim-audit`

## data-analysis

`research-intake` → `document-parsing` → `data-analysis` → `data-figure` → `claim-audit`

## grant-proposal

`research-intake` → `document-parsing` → `grant-template` → `grant-research-content` → `grant-technical-route` → `grant-background` → `literature-synthesis` → `citation-verification` → `claim-audit` → `academic-humanizer` → `grant-review`

## paper-writing

`research-intake` → `document-parsing` → `literature-synthesis` → `paper-drafting` → `citation-verification` → `claim-audit` → `academic-humanizer` → `paper-review`

## patent-disclosure

`research-intake` → `document-parsing` → `patent-disclosure` → `patent-search` → `diagram` → `claim-audit`

## science-figures

`research-intake` → `data-figure` → `diagram` → `nano-banana-figure` → `claim-audit`

## rebuttal

`research-intake` → `paper-review` → `rebuttal` → `citation-verification` → `claim-audit` → `academic-humanizer`

## closeout

`research-intake` → `document-parsing` → `research-closeout` → `claim-audit` → `academic-humanizer`

每个 Skill 具备输入、执行规则、来源与验收要求。真实运行依赖另一个仓库 University-Agent。
